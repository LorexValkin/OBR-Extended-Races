Nexus changelog entry for 1.0.0-rc4 (plain text, paste into the Changelogs tab)
--------------------------------------------------------------------------------

Fixed a crash when quitting the game. OBRPlayableRaces (now 0.5.1) rebuilds the executable's race-name table at startup; earlier versions built the replacement from the mod DLL's own memory, which the game's allocator then tried to free during shutdown and crashed on, every time. The table is now built from the game's own allocator and the buffers it replaces are returned to it. Verified with UNBSE Sentinel: the exit access violation reproduced on every quit before the fix and has not appeared since.

New bundled UE4SS mod: OBRBodyGuard. Body mods (body sliders, morphs) were written for the ten vanilla races and have no body data for these four; measured with NaturalBodyMorph, its rebuild leaves a male Dremora's skin slot holding a dead material and the body renders untextured. OBRBodyGuard checks the four races' bodies once a second and puts the race's own body material (or mesh, should one get swapped) back. Vanilla races are never touched, so body mods keep working everywhere they have data. No configuration needed.

In-game behaviour is otherwise identical. The UE4SS.log registration line now reads 0.5.1, and a new "[BodyGuard] loaded - poll on" line appears at startup.
